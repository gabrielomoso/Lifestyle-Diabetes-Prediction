# Diabetes Prediction Using Lifestyle Factors (NHANES 1999-2004)

This project develops machine learning models to predict diabetes status using lifestyle and demographic data from the National Health and Nutrition Examination Survey (NHANES) 1999-2004.

The analysis includes:
- Data extraction and integration from multiple NHANES files.
- Extensive data preprocessing and feature engineering for lifestyle factors (diet, physical activity, smoking, alcohol).
- A two-stage classification approach:
    1. Identifying individuals with diabetes (Normal vs. Diabetic).
    2. Classifying diabetic patients into Type 1 or Type 2 diabetes.
- Model evaluation using various algorithms, data balancing techniques (SMOTE), and ensemble methods.
- Feature importance analysis to identify key lifestyle predictors.

For a detailed walkthrough of the data processing, analysis, and modeling, please see the Jupyter Notebook: [lifestyle_diabetes.ipynb](lifestyle_diabetes.ipynb)
